# Todo List

A simple and user-friendly **Todo List web application** for creating, managing, and completing daily tasks.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and responsive interface
* Easy task management

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **HTML, CSS, and JavaScript** while building a practical task-management application.
